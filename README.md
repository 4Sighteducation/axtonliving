# Axton Living

Modern landing page for [Axton Living](https://github.com/4Sighteducation/axtonliving) — a property business with a refined, feminine-led approach.

Built with [Astro](https://astro.build) and deployed on Vercel.

## Brand

- Pink: `#fbdade`
- Green: `#14462e`

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

## Build

```bash
npm run build
npm run preview
```

## Deploy

Push to `main` on GitHub — Vercel auto-deploys from `4Sighteducation/axtonliving`.
